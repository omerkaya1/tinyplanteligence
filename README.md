# tinyplanteligence

The project is used for automated irrigation of plants.

## Periferal devices
* ~~Buzzer~~ on-board LED
* Submersible Water Pump (3-5V)

## Sensors
* Soil Moisture Sensor

## Makefile targets

    trial                          build trial programme (may contain different peripherals for testing purposes)
    moisture-sensor                build moisture sensor programme
    help                           print this help and exit
