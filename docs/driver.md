# Driver

A collection of reusable periferal device drivers.

This documentation describes the general approach to using periferal devices via their dedicated drivers.

The code is contained in the [`internal/driver`](../internal/driver) directory, which contains both device drivers and sensor drivers.

## Peripherals

* [`buzzer`](../internal/driver/buzzer) - Buzzer
* [`pump`](../internal/driver/pump) - Water pump
* [`keyboard`](../internal/driver/keyboard) - Keyboard

## Sensors
* [`soil-moisture`](../internal/driver/sensor/soil-moisture) - Soil moisture sensor driver
